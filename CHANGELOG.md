# Changelog

Versions follow `MAJOR.MINOR.PATCH`. Before Release 1 the major number stays 0: a MINOR bump marks a stage the Product
Owner has approved, a PATCH bump marks any other release-worthy merge. 1.0.0 is Release 1. Version changes only in a
small release pull request that edits `package.json` and this file; the tag `vX.Y.Z` goes on the merge commit only when
the Product Owner says so. Every build also carries its short commit, build time and channel (Home footer, tap the
version for About).

## 0.5.0 - 2026-11-24

First numbered version. Trouble Brewing complete; Sects & Violets fully built and validated by the SV-6 sweep (the live
game is still pending); Bad Moon Rising, Travellers, Fabled, Loric and Experimental characters still to come.
Adds the version text in the Home footer and the About dialog.
