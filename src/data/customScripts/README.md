# Custom script files

Import-only scripts, loaded through New Game > Import a script (file upload or JSON paste). They are not built-in
scripts and add no New Game card. Entries are official character ids, so the imported characters stay verified
canonical definitions.

- `treacherous-30th.json`: Treacherous 30th by Guillermo (25 characters). Its recommended Travellers (Thief, Gunslinger,
  Bone Collector, Deviant, Scapegoat) are not listed in the file; choose them in New Game Travellers as for any script.
  Each night is Storyteller-resolved wherever a character is outside the reviewed automation set; see the
  gap analysis for the automation roadmap.
